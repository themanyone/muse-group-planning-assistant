# Muse Group Planning Assistant

**Turning group noise into organized plans.**

Muse Group Planning Assistant (GPA) is an intelligent tool designed to help groups—from hiking clubs and gaming guilds to families and nonprofits—capture and organize their plans from the messy reality of everyday communication.

## 🌟 The Core Idea: The Machine Drafts, The Human Decides

Most group plans are scattered across mailing lists, texts, social media threads, newsletters, paper flyers, and voice notes. Muse GPA listens to these sources and extracts the "noise" into structured drafts.

**Nothing becomes a real plan until a human approves it.**

Every draft (event, task, decision, or reminder) goes through a **Review Queue**. This ensures that the AI's suggestions are verified by a person before they ever touch your calendar or task list. Every draft also comes with **provenance**: you can see exactly which sentence or flyer region the information came from.

## ✨ Key Features

### 📥 Feed it Anything (Sources)
Muse GPA can ingest information from a wide variety of sources:
- **Conversations**: Gather chat exports from WhatsApp, Discord, Slack, etc.
- **Files**: Upload PDFs, HTML, or text documents.
- **Visuals**: Photograph a flyer or a whole noticeboard; Muse GPA will separate and read them.
- **Links**: Drop a URL to fetch event details.
- **Voice**: Record a voice note for transcription and extraction.
- **Email**: Forward newsletters directly to your group's private address.

### 📅 A Reliable Calendar
- **Multiple Views**: Agenda, Month, Week, Day, and a special "Tonight" view.
- **Flyer Wall**: See your month's posters as a visual gallery.
- **iCal Integration**: Subscribe to your group's calendar feed or export events to your personal calendar.
- **Smart Recurrence**: Hand-rolled recurrence engines that handle daylight savings correctly.
- **Notifications**: [Notifications API and Service Workers](https://share.google/aimode/YQIqwfPpexrAeRQAU) are planned.

### 🛠️ Planning & Organization
- **Tasks & Decisions**: Turn discussions into actionable items and recorded decisions.
- **Polls**: Run polls to settle debates; the winner can automatically trigger a plan change.
- **Checklists**: Merge checklists across different events to manage supplies.
- **Budgets**: Track group finances with precision (integer-based for accuracy).

### 🤖 AI-Powered Intelligence
- **Deterministic Extraction**: AI identifies events, tasks, and decisions with high confidence.
- **Smart Date Resolution**: Understands relative dates (e.g., "this Saturday") based on when the message was sent.
- **Agent Seats**: AI agents can participate in your group as "equal principals," following the same rules and subject to the same review queue as humans.

## 🚀 Getting Started

### For Users
Muse GPA is designed to be simple. Once your group is set up, you can start adding sources and reviewing the queue via the web interface or the terminal app.

### For Developers
This project is built with a modern Python stack.

**Prerequisites:**
- `uv` (Python package manager)

**Installation & Running:**
```bash
# Clone the repository
git clone <repository-url>
cd muse-group-planning-assistant

# Run the application
bash run.sh

# Run the test suite
bash test.sh
```
